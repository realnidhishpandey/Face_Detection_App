# Face_Detection_App

🚀 Features
Real-time face detection and expression recognition

Displays expressions with confidence levels

Start/Stop face detection with buttons

Friendly, personalized phrases based on emotions

Clean, responsive UI

🔘 Start and Stop Detection
Start Detection: Activates the webcam and starts facial expression detection.

Stop Detection: Stops the detection and freezes the webcam.


🧠 Technologies Used
React

face-api.js

WebRTC (via navigator.mediaDevices)

JavaScript (ES6+)

CSS (for styling)
